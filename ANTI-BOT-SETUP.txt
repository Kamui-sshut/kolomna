ЗАЩИТА ОТ БОТОВ — НАСТРОЙКА CLOUDFLARE TURNSTILE

Важно: GitHub Pages — статический хостинг. Проверить Turnstile секретным ключом только в браузере невозможно. Поэтому в архив включён Cloudflare Worker, который выполняет серверную проверку и ограничивает частоту проверок по IP через Cloudflare KV.

ПОКА НЕ ЗАПОЛНЕНЫ КЛЮЧИ И НЕ РАЗВЁРНУТ WORKER, ПОЛНОЦЕННАЯ СЕРВЕРНАЯ АНТИБОТ-ЗАЩИТА НЕ АКТИВНА. На сайте остаётся honeypot и локальная пауза между запросами — это дополнительная, но не полноценная защита.

1. В Cloudflare Dashboard открой Turnstile и создай виджет для домена сайта (включая github.io, если сайт пока на GitHub Pages).
2. Скопируй Site Key и Secret Key.
3. Создай Cloudflare Workers KV namespace, например EVAC_RATE_LIMIT.
4. В папке worker скопируй wrangler.toml.example в wrangler.toml, укажи ID KV namespace и точный origin сайта в ALLOWED_ORIGIN. Для GitHub Pages origin выглядит как https://username.github.io (без пути репозитория).
5. В Cloudflare Worker добавь секрет: npx wrangler secret put TURNSTILE_SECRET
6. Разверни Worker из папки worker: npx wrangler deploy.
7. В корневом turnstile-config.js укажи:
   window.EVAC_CONFIG = {
     turnstileSiteKey: "ТВОЙ_SITE_KEY",
     verificationEndpoint: "https://ИМЯ-WORKER.ТВОЙ-АККАУНТ.workers.dev"
   };
8. Опубликуй обновлённый сайт и проверь проверку Turnstile на своём домене.

Worker проверяет токен у Cloudflare, проверяет Origin/hostname, отклоняет заполненное скрытое поле и ограничивает число проверок с одного IP (12 за 10 минут через KV).

Карта и геокодирование:
- Геолокация браузера запрашивается только после нажатия посетителем кнопки «Моё местоположение».
- Адреса ищутся через Nominatim/OpenStreetMap, автомобильный маршрут и километраж — через OSRM demo service.
- Это публичные сервисы с ограничениями и без гарантии SLA. Для большого коммерческого трафика подключите платный геокодер/маршрутизатор или собственный серверный маршрутный сервис.
- Расчёт является предварительным; водитель подтверждает итоговую стоимость.

Форма карты ничего не отправляет в Telegram или на почту: username/бот и канал приёма заявок ещё не предоставлены. Сейчас карта строит маршрут и рассчитывает цену; связь с водителем — по телефону.
