ПОДКЛЮЧЕНИЕ ВСТРОЕННОЙ КАРТЫ ЯНДЕКС.КАРТ ДЛЯ «ЭВАКУАТОР КОЛОМНА»

Зачем это нужно
На сайте реализован встроенный выбор двух точек: сначала место подачи (А), затем место доставки (Б). После выбора обеих точек Яндекс.Карты строят автомобильный маршрут, а сайт получает дорожное расстояние и автоматически считает ориентировочную стоимость по выбранному тарифу.

1. Получите ключ JavaScript API Яндекс.Карт:
   https://developer.tech.yandex.ru/keys/
   Создайте ключ именно для JavaScript API 2.1.
2. В настройках ключа укажите разрешённые домены сайта (например, ваш-домен.ru и ваш-логин.github.io). Не оставляйте ключ без ограничений по доменам.
3. Откройте turnstile-config.js в корне сайта.
4. Найдите yandexMapsApiKey и вставьте свой ключ между кавычками:
   yandexMapsApiKey: "ВАШ_КЛЮЧ_ЯНДЕКС_КАРТ"
5. Сохраните файл и загрузите его в корень GitHub-репозитория вместе с index.html, styles.css, script.js и папкой assets.
6. Откройте сайт по HTTPS и проверьте карту.

Как пользоваться картой посетителю
- Нажать «Выбрать обе точки на карте».
- Разрешить геолокацию (необязательно) или нажать на карту, чтобы поставить точку А.
- После выбора А автоматически активируется выбор точки Б.
- Нажать на карту в месте доставки.
- Карта строит автомобильный маршрут; расстояние и предварительная стоимость выводятся на странице.
- Для изменения точки нажать «Точка подачи» или «Куда доставить» и выбрать новое место.

Важно
- API-ключ нужен для загрузки карты, геокодирования адресов и построения маршрута. Без ключа карта не сможет работать; сайт покажет подсказку вместо пустой карты.
- По документации Яндекса запросы маршрутизации и геокодирования могут тарифицироваться. Проверьте действующие условия, лимиты и подключённые услуги в кабинете разработчика перед публикацией.
- API-ключ находится в браузерном коде, поэтому обязательно ограничьте его разрешёнными доменами в кабинете Яндекса.
- Геолокация запрашивается только после нажатия посетителем кнопки «Моё местоположение» и требует HTTPS и разрешения браузера.
- Расчёт предварительный: подача + дорожное расстояние × тариф + дополнительное ожидание. Итоговую цену подтверждает Артемий.
- Для стабильной работы на iPhone Safari используйте опубликованный сайт по HTTPS.
