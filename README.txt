ЭВАКУАТОР КОЛОМНА — ВЕРСИЯ С ВНЕШНИМИ КАРТАМИ

Что изменено в этой версии:
- Удалена встроенная карта OpenStreetMap/Leaflet, которая показывала 403 Access blocked из-за ограничений публичного tile-сервера.
- Вместо неё добавлены переходы в Яндекс Карты, 2ГИС, Google Maps и Apple Карты.
- Ссылки на Яндекс, Google и Apple формируются из адресов подачи/доставки. Если посетитель разрешит геолокацию, координаты текущего места будут использованы как точка отправления.
- 2ГИС открывает поиск адреса доставки. Для маршрутов с координатами 2ГИС поддерживает отдельный формат ссылок; при текстовых адресах поиск надёжнее и позволяет выбрать точку в самом приложении.
- Добавлено поле для ввода дорожного расстояния, которое посетитель видит в выбранном картографическом сервисе. После ввода километража калькулятор пересчитывает цену по утверждённому тарифу.
- Добавлены прямые контакты: Telegram https://t.me/Artemy1412 и MAX https://max.ru/9373111176.
- Встроенные OSM-тайлы, запросы к Nominatim и публичному OSRM удалены: сайт больше не зависит от заблокированного слоя карты.

Важно:
- Геолокация запрашивается только после нажатия кнопки и разрешения посетителя. На GitHub Pages она доступна по HTTPS.
- Расстояние и цена предварительные. Для точного расчёта пользователь сверяет дорожный километраж в выбранном сервисе и вводит его в калькулятор; окончательную цену подтверждает Артемий.
- Сайт не отправляет адреса или заявки на сервер. Кнопки только открывают выбранные картографические сервисы.
- Антибот-проверка Cloudflare Turnstile не нужна для локального расчёта и внешнего перехода. Если позже будет добавлена отправка заявок с сайта, Turnstile нужно подключить с серверной проверкой токена через Worker. Наличие файлов Worker в архиве само по себе не означает, что защита уже активна.

Публикация:
1. Распакуйте архив.
2. Загрузите содержимое в корень GitHub-репозитория, где находится index.html.
3. Сохраните папку assets/ и файлы styles.css, script.js, turnstile-config.js.
4. Дождитесь завершения GitHub Pages Actions и обновите сайт без кэша.
